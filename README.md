# Warp Color Finder

Pick colors from any image. Minimal black-and-white, open source.

- Drag and drop upload
- Click to get HEX / RGB / HSL
- Close tones + harmonies
- One-click copy
- Download as CSS / TXT / PNG
- Light / dark theme (sun / moon), saved in `localStorage`
